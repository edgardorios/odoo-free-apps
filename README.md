# Odoo Free Apps

Welcome to **Odoo Free Apps**! This is a place where I, [Edgardo Rios](https://github.com/edgardorios), share free Odoo apps that you can find on [Odoo Apps](https://apps.odoo.com). These apps are open-source, easy to use, and made to help your Odoo setup.

## Current App

Right now, there’s only one app in this repository:

- **[Ribbon Banner](ribbon_banner/)**: Adds a ribbon to your Odoo that shows the environment (like DEV or TEST) and database name. You can change its text, colors, and transparency in Odoo’s settings. Great for keeping track of different setups! [Check it out on Odoo Apps](https://apps.odoo.com/apps/modules/18.0/ribbon_banner/).

## Future Apps

I hope to add more apps to this repository in the future, but I’m not sure when or if that will happen. If I create new apps, I’ll include them here when they’re ready.

## How to Install

Each app has its own `README.md` file with simple steps to install it. Go to the app’s folder (like `ribbon_banner/`) to find those instructions.
