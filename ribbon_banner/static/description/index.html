Ribbon Banner

The Ribbon Banner app adds a customizable ribbon to your Odoo instance, displaying the environment (e.g., DEV, TEST, STAGING) and database name in the top-left corner. Perfect for multi-environment setups to avoid confusion!

Features

  • Displays a ribbon banner with environment and database name.
  • Configure in Settings > General Settings:
    • Banner Text: Set custom text (e.g., "DEV").
    • Banner Opacity: Set opacity between 0.0 (fully transparent) and 1.0 (fully opaque).
    • Banner Text Color: Choose text color.
    • Banner Background Color: Choose via color picker.
  • Lightweight and easy to install.
  • Free and open-source under LGPL-3.

Installation

Install from Odoo Apps:

  1. Visit Ribbon Banner on Odoo Apps and click Download to get the ZIP file.
  2. Extract the ZIP to obtain the ribbon_banner folder.
  3. Copy the ribbon_banner folder to your Odoo addons directory.
  4. Log in to Odoo with admin rights.
  5. Go to Settings > About and click Activate the developer mode.
  6. Go to Apps and click Update Apps List.
  7. Search for "Ribbon Banner" and click Install.
  8. Configure in Settings > General Settings.
