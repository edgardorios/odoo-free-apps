Ribbon Banner

The Ribbon Banner module adds a simple, customizable ribbon to the top-left corner of your Odoo screens. It's useful for marking environments (like DEV or STAGING) and showing the database name to help users avoid confusion.

Features

  • Environment Ribbon: Displays a small banner on the top-left with custom text.
  • Customizable:
    • Text
    • Text color
    • Background color
    • Opacity
  • Odoo Settings Integration: All configurations available under Settings > Ribbon Banner

Installation

  1. Copy the ribbon_banner folder to your Odoo addons directory (e.g., /odoo/addons/).
  2. Enable Developer Mode in Odoo.
  3. Go to Apps > Update Apps List.
  4. Search for "Ribbon Banner" and click Activate.
  5. Go to Settings > Ribbon Banner to configure.

Configuration

In Settings > Ribbon Banner, you can customize the ribbon:

  • Banner Text: Enter the label (e.g., DEV, STAGING).
  • Opacity: Set transparency level (0.0 to 1.0).
  • Text Color: Choose any color for the ribbon text.
  • Background Color: Pick a background color.
