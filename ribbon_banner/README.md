# Ribbon Banner Module for Odoo 18

The **Ribbon Banner** module adds a small customizable ribbon to the top-left corner of your Odoo screens. It’s useful for identifying environments (e.g., DEV, STAGING, TEST) and avoiding mistakes in multi-instance setups.

## Features

- Shows a ribbon with the environment name and database.
- Fully configurable from **Settings > Ribbon Banner**:
  - Text
  - Background color
  - Text color
  - Opacity

## Installation

1. Copy the `ribbon_banner` folder to your Odoo addons directory.
2. Enable Developer Mode in Odoo.
3. Go to **Apps** > **Update Apps List**.
4. Search for “Ribbon Banner” and click **Activate**.
5. Go to **Settings > Ribbon Banner** to configure.

## Configuration

In **Settings > Ribbon Banner**, you can set:

- **Banner Text** (e.g., “STAGING”)
- **Opacity** (0.0 to 1.0)
- **Text Color**
- **Background Color**
